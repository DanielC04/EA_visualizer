# Evolutionary algorithm visualizer
This is simple React app, that visualizes how Random local search and (1 + 1) EA work on simple test functions. Here binary strings are represented using a nxn matrix where the pixel at the position matrix[y][x] is set to one exactly when the bistring is one at the position y * width + x.
A current version of the visualizer can be found here: ![https://ea-visualizer.dcermann.de]

## Getting started
- clone the repo
- run ``npm install``
- run ``npm run start``
- start developing :)
